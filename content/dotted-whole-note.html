This is how you work out the value of the dotted whole note.

If your answer was correct, congratulations - you understand how to use dotted notes. If you made a mistake click on the link below (or close this window) to go back to the page explaining how to calculate the value of a dotted note.

Remember: The dot takes half the value of the note. In the case of the dotted semibreve (whole note) this means the dot takes 2 beats. Adding this to the original value of the note (4) we get 6 beats.
