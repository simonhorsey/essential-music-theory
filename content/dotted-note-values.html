Value of a dotted semibreve

Hi,

A dotted semibreve has a value of 6 crotchets.

The dot adds half the value of the note to itself (makes it half as long again).

Since a semibreve is worth 4 crotchets, and half of 4 is 2, this is added to make 6.

You can find more info about how to work out the value of dotted notes by clicking on the link.
